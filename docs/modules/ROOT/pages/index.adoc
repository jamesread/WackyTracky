= WackyTracky

WackyTracky is a minimal, keyboard-friendly task and list tracker. It
gives you simple task and list tracking with a clean interface that
works well for power users and GTD-style workflows.

.List view — tasks with priorities, tags, contexts, and due dates
image::screenshots/list-work.png[List view — tasks with
priorities, tags, contexts, and due dates]

== What you can do

* *Tasks and lists* — Organize tasks into lists, with support for nested
tasks, tags, and contexts.
* *todo.txt compatibility* — The default storage uses the
http://todotxt.org[todo.txt] format, so your data stays in plain text
files you can edit or sync with other tools.
* *Self-hosted* — Run it yourself with Docker; your data stays on your
machine or server.

== Get started

[arabic]
. *xref:install/docker-compose.adoc[Install with Docker Compose]* —
Recommended way to run WackyTracky. One `docker-compose.yml` and a small
config file are all you need.
. *Choose a backend* — WackyTracky can store tasks in different
backends. *xref:backends/todotxt.adoc[todo.txt]* is the default and
recommended option and is where most development and testing happens.
Other options: xref:backends/neo4j.adoc[Neo4j],
xref:backends/yamlfiles.adoc[YAML files].
